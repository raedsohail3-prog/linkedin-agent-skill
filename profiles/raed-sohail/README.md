# Raed Sohail's LinkedIn files

- `voice.md`: voice profile every skill reads. Copy to `~/.claude/linkedin/voice.md`.
- `posts.md`: published posts, the next draft, and the post pattern to reuse.
- `log.md`: published post log. Copy to `~/.claude/linkedin/log.md`.

To set up a new machine:

```bash
mkdir -p ~/.claude/linkedin
cp profiles/raed-sohail/voice.md profiles/raed-sohail/log.md ~/.claude/linkedin/
```
